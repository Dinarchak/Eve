# Eve — Voice Assistant with MCP & Local LLMs

> Голосовой ассистент с нейросетью в роли «мозга» и простым механизмом подключения MCP-серверов.  

## 🎯 О проекте

**Eve** — это экспериментальный голосовой ассистент, который учится работать с **Model Context Protocol (MCP)** и REPL-модулями Python. Проект находится в активной фазе исследования: архитектура ещё не зафиксирована, и мы учимся на ходу, подключая MCP-серверы и строя цикл общения с нейросетью.

**Текущее состояние (Alpha):**
- ✅ Цикл общения с Ollama (`cycle.py`)
- ✅ Подключение MCP-серверов и подготовка инструментов (`servers_manager.py`)
- ✅ Конфигурация через `eve_config.json` (`settings.py`)
- ❌ STT (Speech-to-Text) — **не реализовано**
- ❌ TTS (Text-to-Speech) — **не реализовано**
- ❌ Облачные LLM-провайдеры — **в планах**
